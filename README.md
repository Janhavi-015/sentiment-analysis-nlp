# Sentiment Analysis using NLP

## Overview

This project implements a Natural Language Processing pipeline
for classifying text reviews into positive and negative sentiments.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Logistic Regression
- Google Colab

## Methodology

1. Dataset preparation
2. Text preprocessing
3. TF-IDF feature extraction
4. Train-test split
5. Logistic Regression model training
6. Model evaluation
7. Sentiment prediction

## Model

TF-IDF is used to convert text into numerical features.
A Logistic Regression classifier is then trained to classify
the sentiment of the reviews.
